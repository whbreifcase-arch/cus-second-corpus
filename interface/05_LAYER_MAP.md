# Interface · The Layer Map

Every physical component manifests one of the **four existing layers**
([Slice 1 · 02_WORLD](../slice-1/02_WORLD.md)). This table is the whole claim of the interface module:
there is nothing new here to *own* — only new ways to *show and hold* what the four layers already own.

| Layer | What it owns | Physical manifestation |
|---|---|---|
| **Definition** | static, referenced truth (the JSON in code) | *rendered onto* Packet-card backs & reference surfaces — a **kernel-facing Presentation**, not the source |
| **Procedure** | the owned resolution methods | the instructions **enacted** when components are used (a strike, a Counter, the Aftermath) |
| **Instance** | what is true right now | tokens, sliders, dials, model placement, inserts, temporary markers |
| **Presentation** | translation / mirror of another owner | Packet-card **fronts and backs**, Frame windows, the **Archetype** name & silhouette, icons, card layout |

Two things this table makes explicit:

- **The card back is Presentation, not Definition.** The JSON *in code* is the Definition; the print is a kernel-facing *view* of it ([02_PACKET_CARDS.md](02_PACKET_CARDS.md)). So "Definition" and "Presentation" both touch the card — the *authority* is in code, the *card* renders it.
- **Position and containment** ride along physically too: where a model stands is Position; the Book nook and the Frame's slots are containment ([04_BOOK_AND_CARAVAN.md](04_BOOK_AND_CARAVAN.md)). Neither is a new layer.

## The authority rule, physically
Presentation **translates; it never becomes a second authority.** So the corrections always run one way:

```
card face  ⟂  Definition (code)   →  Definition wins, reprint the card
token      ⟂  Instance            →  Instance wins, fix the token
geometry   ⟂  FrameSpec           →  FrameSpec wins, re-cut the part
```

**Code all the way down; physical meaning all the way up.** Meaning is not inserted as a middleman
object — it becomes *visible* when the authored system is properly packaged.
