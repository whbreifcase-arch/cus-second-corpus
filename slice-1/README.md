# Vertical Slice 1 — One figure acts, two figures oppose

The first real Second Corpus content. It rebuilds the **smallest closed loop** the Kernel can run:
a single figure perceives, spends Agency, invokes a Capability, a Procedure resolves it, and State
changes — then a second figure opposes it, all the way to a melee exchange with a **Counter**.

Built from **Architecture Zero** (dependency-ordered) and the **13 signed rulings** (CON-0001…0013
in `cus-concordance`). Everything here is authored to those rulings, not copied from the frozen
First Corpus.

## Deliberately deferred to Slice 2+
The Mind channel (**Morale** damage, the **Nerve** save, the **Morale check**), the **Circle**,
**formation movement**, and all **Persistence** (Wounds → Injury → Scar, the Caravan, campaign).
Slice 1 is Body-channel only, Squares only, one battle only.

## The loop this slice closes
```
perceive Position → choose intent → spend Agency → invoke a PACKET
   → world constrains (named fields) → owned Procedure resolves (roll → Grade → Effect)
   → State/Position changes → the Event is done
```
